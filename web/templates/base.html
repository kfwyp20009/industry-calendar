导出日历

将行业事件导出到 iPhone 日历或其他日历 App。

方式一：下载 ICS 文件

下载后发送到手机，打开即可导入日历。

方式二：订阅日历（自动同步）

将下方地址添加到 iPhone 日历订阅，之后系统事件更新后手机自动同步。

iPhone 设置方法：
设置 → App → 日历 → 账户 → 添加账户 → 其他 → 添加订阅日历，粘贴上方地址。
局域网访问： 如果手机和电脑在同一个 WiFi 下，把地址中的 localhost 换成电脑的局域网 IP（如 192.168.1.100）。 Windows 上用 ipconfig 查看。
