# 行业投资日历系统

跟踪 A 股前沿主题的**催化事件日历**，提前发现投资线索，辅助事件驱动型投资决策。

> 行业的股价上涨往往有催化剂事件——政策出台、技术突破、重要会议、产品发布。本系统帮你把未来一年各行业已知的催化事件梳理成日历，看清节奏，提前布局。

---

## 快速开始

### 环境要求

- Python 3.8+
- Flask + PyYAML

```bash
pip install flask pyyaml
python launch.py
```

浏览器打开 `http://localhost:5000` 即可使用。

Windows 用户也可直接双击 `start.bat`，Mac/Linux 用户双击 `start.sh`。

## 典型使用流程

一个事件驱动投资者的日常使用路径：

```
周一打开仪表盘  →  看本月哪些行业催化最密集
   ↓
点进高热度行业  →  看具体有哪些事件要发生
   ↓
查看行业详情   →  研究该行业核心标的池
   ↓
切换到全年全景  →  判断催化节奏是短期脉冲还是全年主线
   ↓
打开联动分析   →  看看这个事件还会带动哪些其他行业
```

## 各页面详细使用说明

### 仪表盘

**入口：** 首页 / `Dashboard`

仪表盘是每天打开系统后第一眼看到的总览页面，集中展示当前最重要的信息。

| 模块 | 内容 | 怎么看 |
|------|------|--------|
| 本月催化热度 | 各行业本月即将发生的事件数量 × 重要性加权，按热度排序 | 热度越高，说明该行业本月事件越密集，短期关注度可能上升 |
| 行业 ETF 行情 | 各行业对应 ETF 的近期涨跌幅 | 结合事件看：如果事件还没落地但 ETF 已经大涨，可能已提前定价 |
| 回测概览 | 基于历史事件的信号收益统计 | 评估该行业历史事件驱动规律是否有效 |

**使用示例：** 看到"低空经济"本月热度排名第一，说明近期有一批政策/会议密集落地，可以进入该行业详情页查看具体事件列表。

---

### 事件日历

**入口：** 导航栏 → `事件日历`

按月展示所有行业全部事件的日历视图。

**你能看到的信息：**

- 每个日期格子里列出当天的事件标题，左侧色条按重要性着色（1~4 星对应不同颜色深度）
- 左侧筛选栏：按行业、事件类型（政策/技术/产品/会议）、阶段（预期/跟踪/确认）筛选
- 点击事件标题弹出详情卡，显示完整的事件描述

**怎么用：**

1. 查看本月有哪些值得关注的事件
2. 筛选"重要性 = 4 星"的事件，只关注最重要的大催化
3. 筛选阶段为"预期"的事件——这些还没落地，存在提前布局的时间窗口
4. 月度切换，提前规划未来 1~3 个月的关注重点

**使用示例：** 筛选"低空经济 + 重要性 4 星 + 预期阶段"，看到"2026 全国低空经济发展大会"在两个月后。说明至少还有一个月观察窗口，可以逐步研究该行业核心标的。

---

### 全年全景

**入口：** 导航栏 → `全年全景`

把所有行业的事件按时间顺序铺开到全年时间轴上。

**你能看到的信息：**

- 横向时间轴（1~12 月），每个事件以圆点或色块分布在对应月份
- 每个行业一行，一眼看到该行业全年的催化分布
- 事件密集处自动聚合，缩放查看具体事件

**怎么用：**

1. **判断主线 vs 脉冲：** 如果一个行业的事件均匀分布在全年（如"人工智能"每月都有会议/产品），可能是全年持续性主线；如果集中在某个月（如"核聚变"集中在 Q4 会议季），更多是脉冲式机会
2. **跨行业比对：** 把 13 个行业放在一起看，资源应该集中配置在催化最密集的季度
3. **提前规划：** Q3 哪些行业催化最多？提前两个月开始研究，等市场开始关注时你已经准备好

**使用示例：** 从全景图看到 Q3（7~9 月）6G 通信、卫星互联网、商业航天三个行业的事件密集重叠，说明 Q3 可能有一条"太空经济"主线，可以提前做跨行业联动分析。

### 行业详情

**入口：** 点击仪表盘的热度行业 / 导航栏 → `行业详情`（需要先选择行业）

每个行业的深度研究页面，包含两大部分。

**上半部分——事件列表：**

| 信息 | 说明 |
|------|------|
| 事件时间线 | 该行业所有事件按时间排序 |
| 重要性标记 | 星级标注，一眼看到关键节点 |
| 阶段标签 | 预期（未落地）/ 跟踪（进行中）/ 确认（已落地） |
| 描述 | 每个事件的详细背景 |

**下半部分——核心标的池：**

```
┌─────────┬─────────┬─────────────────┬──────────┐
│  代码    │  名称    │  入选理由         │ 细分板块  │
├─────────┼─────────┼─────────────────┼──────────┤
│ 600000  │ 示例A    │ 6G 射频芯片龙头   │ 芯片     │
│ 600001  │ 示例B    │ 低空经济空管系统   │ 基建     │
└─────────┴─────────┴─────────────────┴──────────┘
```

- 代码和名称：方便复制到交易软件中加到自选
- 入选理由：说明该标的为什么受益于这个行业的催化事件
- 细分板块：该行业内部的不同细分方向

**怎么用：**

1. 确认某个行业的催化逻辑后，在这里找到对应的核心受益标的
2. 看事件的时间节点，倒推出最佳的买入观察窗口
3. 结合细分板块判断布局方向——例如"自动驾驶"行业中，事件是"L3 立法"，侧重关注"决策系统"细分板块的标的

### 核心标的

**入口：** 导航栏 → `核心标的`

把全行业所有核心标的汇总到一张表里，方便横向对比。

**你能看到的信息：**

- 标的所属行业、代码、名称、入选理由、细分板块
- 支持按行业筛选、按细分板块分组

**怎么用：**

1. **跨行业选股：** 如果你的投资风格是分散配置，这里可以看到不同行业分别有哪些可关注的标的
2. **追踪覆盖：** 把核心标的加入自选后，定期回来看对应行业的事件进度，判断持有逻辑是否还在
3. **横向对比：** 同一个细分板块在不同行业之间可能交叉出现，帮你发现某个细分方向是多个行业的交汇点

---

### 联动分析

**入口：** 导航栏 → `联动分析`

当一个大事件同时影响多个行业时，联动图谱帮你一目了然地看到这种交叉关系。

**你能看到的信息：**

- 图谱中心是一个事件或行业，周围辐射出被影响的其他行业
- 连线表示"某事件同时影响 A 行业和 B 行业"
- 联动强度通过连线粗细/颜色表示（强 / 中 / 弱）

**怎么用：**

1. **找交叉点：** 一个事件如果同时催化 3 个以上的行业，说明这是个市场级别的焦点事件，值得更高关注
2. **找溢出机会：** A 行业的大催化（如"6G 标准冻结"），可能顺带带动 B 行业（卫星互联网），联动分析帮你发现这些间接机会
3. **风险提示：** 如果多个行业的联动事件集中发生在同一个月，市场可能出现主题轮动加速，注意节奏

**内置联动示例：**

| 联动事件 | 影响行业 |
|----------|---------|
| 6G 标准冻结 | 6G 通信、卫星互联网、人工智能 |
| 低空经济试点扩容 | 低空经济、自动驾驶、数据要素 |

## 数据模型：什么是"催化事件"？

每个事件包含以下字段：

| 字段 | 说明 |
|------|------|
| 日期 | 事件预计发生的时间 |
| 标题 | 事件名称（如"2026 世界 6G 大会"） |
| 重要性 | 1~4 星，4 星为最重要 |
| 类型 | 政策 / 技术 / 产品 / 会议 |
| 描述 | 事件详情 |
| 阶段 | 预期（还没落地，提前布局）→ 跟踪（正在发生）→ 确认（已落地，验证判断） |

**重要性分级参考：**

| 星级 | 含义 | 例子 |
|------|------|------|
| 4 星 | 行业级大催化，可能带来板块整体行情 | 国家级政策出台、国际标准冻结 |
| 3 星 | 重要事件，影响细分方向 | 行业大会、头部公司产品发布 |
| 2 星 | 常规事件，局部影响 | 地方试点、学术会议 |
| 1 星 | 信息参考，方向性关注 | 研究进展、媒体报道 |

**阶段说明：**

- **预期 → 跟踪 → 确认** 是一个事件从"未发生"到"正在发生"再到"已落地"的生命周期
- **预期**阶段的事件最有研究价值——市场还没充分定价，有时间做功课
- **确认**阶段的事件用于复盘：事件落地后市场反应如何？下次类似事件可参考

系统根据事件类型和阶段，自动在仪表盘上计算**"催化热度"**——某个行业在某个时间段内高重要性事件的密度。

## 自定义行业

在 `data/industries/` 下创建 `YAML` 文件即可添加你自己的行业。

```yaml
industry: "你的行业名称"
description: "一句话描述这个行业的投资逻辑"
tags: [标签1, 标签2]
updated: "2026-06-01"

core_stocks:
  - code: "000001"
    name: "股票名称"
    reason: "为什么选这只标的"
    sector: "细分板块"

events:
  - date: "2026-07-15"
    title: "事件标题"
    importance: 3        # 1~4，4 为最重要
    type: "政策"          # 可选：政策 / 技术 / 产品 / 会议
    description: "事件详情的文字描述"
    category: "预期"      # 可选：预期 / 跟踪 / 确认
```

- 文件名建议按 `01-行业名称.yaml` 格式命名，系统按文件名排序加载
- 添加文件后重启服务即可生效
- 如果要修改已有行业的事件，直接编辑对应的 YAML 文件，重启即可

## 目录结构

```
data/
  industries/       ← 行业事件 YAML 文件，新增/编辑行业都在这里
  stocks/            # 核心标的池数据
  etf_mapping.yaml   # 行业与 ETF 的映射关系
  cross-industry.yaml    # 跨行业联动配置
web/
  app.py             # Flask 后端
  templates/         # HTML 模板
launch.py            # 一键启动
```
