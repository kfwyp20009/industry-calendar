# 行业投资日历系统

覆盖 **11 个前沿行业**的 A 股主题投资日历，支持本地 Web 展示和 Hermes Agent 推送。

|---|------|---------|---------|
| 1 | 6G通信 | 技术+标准 | 标准年，R20/R21时间表是最大催化 |
| 2 | 低空经济 | 政策+基建 | 从政策走向订单落地，eVTOL取证年 |
| 3 | 卫星互联网 | 基建+国防 | 持续组网，业绩开始兑现 |
| 4 | 机器人零部件 | 技术+量产 | 特斯拉供应商决定板块方向 |
| 5 | 具身智能 | 技术+产品 | 早期赛道，IPO+大模型是催化 |
| 6 | 绿氢氨醇 | 政策+能源 | IMO碳税是分水岭（10月MEPC 85） |
| 7 | 数字人民币 | 政策+金融 | 2.0改革建设高峰期 |
| 8 | AI大模型/应用 | 技术+产品 | 应用落地元年，看变现能力 |
| 9 | 半导体/国产替代 | 技术+安全 | 美国大选后出口管制变数 |

## 启动方式

### 本地 Web 版（推荐）

**Windows**: 双击 `start.bat`，自动打开浏览器
**Mac/Linux**: 双击 `start.sh` 或运行 `bash start.sh`

浏览器访问 `http://localhost:5000`

功能：仪表盘 / 事件日历 / 全年全景 / 行业详情 / 核心标的池 / 联动地图

### Hermes Agent 推送

```bash
# 安装到 Hermes（需先安装 Hermes Agent）
bash install.sh
# 或使用自解压安装包
bash install-industry-calendar.sh
```

推送节奏：早报 8:30 / 午报 12:30 / 晚报 18:00 / 周报 周六 / 月报 每月1日

## 项目结构

```
web/                # Web 应用
  app.py            # Flask 后端
  templates/        # HTML 模板
data/               # 结构化事件数据（YAML）
  industries/       # 11个行业事件日历
  stocks/           # 核心标的池
  cross-industry.yaml  # 跨行业联动
reports/            # 编译生成的日历报告
prompts/            # Hermes prompt 模板
scripts/            # 维护脚本
start.bat / start.sh  # 一键启动脚本
```

## 数据来源

各行业策略框架 + 新闻事件监控列表（位于 `hangyefenxi/` 各行业目录）。
